<!-- Philosophical Worldview -->
<div align="center">
  <h2>🧠 Pandangan Dunia</h2>
  
  <p style="text-align: justify; max-width: 800px; margin: 0 auto; line-height: 1.8; color: #c9d1d9;">
    Saya menyadari bahwa alam semesta ini bisu dan tidak membawa makna objektif apa pun sejak awal. Namun, alih-alih menyerah pada keputusasaan atau berlindung di balik ilusi dogma sosial (sebuah <a href="https://en.wikipedia.org/wiki/Philosophical_suicide" target="_blank" style="color: #58a6ff; text-decoration: none;"><strong>BUNUH DIRI FILOSOFIS</strong></a>), saya memilih untuk memeluk <a href="https://en.wikipedia.org/wiki/Absurdism" target="_blank" style="color: #58a6ff; text-decoration: none;"><strong>ABSURDISME</strong></a>.
  </p>
  
  <p style="text-align: justify; max-width: 800px; margin: 0 auto; line-height: 1.8; color: #c9d1d9;">
    Dalam hiruk-pikuk interaksi sosial yang penuh <em>noise</em> dan perdebatan sirkular, posisi saya adalah seorang pengamat. Saya meragukan norma-norma yang ada melalui lensa <a href="https://en.wikipedia.org/wiki/Skepticism" target="_blank" style="color: #58a6ff; text-decoration: none;"><strong>SKEPTISISME</strong></a> pragmatis—memfilter omong kosong dan hanya mengekstraksi hal-hal yang memiliki utilitas serta fungsi riil.
  </p>
  
  <p style="text-align: justify; max-width: 800px; margin: 0 auto; line-height: 1.8; color: #c9d1d9;">
    Bagi saya, jika realitas ini kosong, maka kitalah yang harus menjadi arsitek atas nilai kita sendiri, layaknya semangat <a href="https://en.wikipedia.org/wiki/%C3%9Cbermensch" target="_blank" style="color: #58a6ff; text-decoration: none;"><strong>ÜBERMENSCH</strong></a>. Di sanalah software engineering masuk. Menulis kode, merancang arsitektur sistem, dan memoles UI yang murni esensial bukanlah sekadar tuntutan teknis. Itu adalah bentuk pemberontakan eksistensial saya. Di tengah dunia yang pada dasarnya chaos, saya memaksakan struktur, rasionalitas, dan ketertiban melalui logika deterministik.
  </p>
