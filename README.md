## `02` — THE YAPPING

Saya menyadari bahwa alam semesta ini bisu dan tidak membawa makna objektif apa pun sejak awal. Namun, alih-alih menyerah pada keputusasaan atau berlindung di balik ilusi dogma sosial (sebuah <a href="https://en.wikipedia.org/wiki/Philosophical_suicide"><b>BUNUH DIRI FILOSOFIS</b></a>), saya memilih untuk memeluk <a href="https://en.wikipedia.org/wiki/Absurdism"><b>ABSURDISME</b></a>. 

Dalam hiruk-pikuk interaksi sosial yang penuh *noise* dan perdebatan sirkular, posisi saya adalah seorang pengamat. Saya meragukan norma-norma yang ada melalui lensa <a href="https://en.wikipedia.org/wiki/Skepticism"><b>SKEPTISISME</b></a> pragmatis—memfilter omong kosong dan hanya mengekstraksi hal-hal yang memiliki utilitas serta fungsi riil.

Bagi saya, jika realitas ini kosong, maka kitalah yang harus menjadi arsitek atas nilai kita sendiri, layaknya semangat <a href="https://en.wikipedia.org/wiki/%C3%9Cbermensch"><b>ÜBERMENSCH</b></a>. Di sanalah *software engineering* masuk. Menulis kode, merancang arsitektur sistem, dan memoles UI yang murni esensial bukanlah sekadar tuntutan teknis. Itu adalah bentuk pemberontakan eksistensial saya. Di tengah dunia yang pada dasarnya *chaos*, saya memaksakan struktur, rasionalitas, dan ketertiban melalui logika deterministik.
